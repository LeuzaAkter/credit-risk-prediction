# credit-risk-prediction
Machine learning web application for credit risk classification using Python and Streamlit.
A machine-learning portfolio project that explores credit-risk classification and provides a simple interactive Streamlit interface for predicting whether an applicant is labelled as a **good** or **bad** credit risk by a trained model.

> **Important:** This is an educational portfolio project, not a credit-decision system. Predictions are not financial advice and must not be used to approve or reject real applicants. The dataset is limited, model performance is modest, and the model has not been validated for real-world use, fairness, or regulatory compliance.

## Project overview

The project uses applicant attributes to classify credit risk. The notebook explores the data, prepares selected features, compares several classification algorithms, tunes hyperparameters with cross-validation, and saves the selected Extra Trees model for use in the web app.

### Features used

- Age
- Sex
- Job category (0–3)
- Housing
- Savings account category
- Checking account category
- Credit amount
- Credit duration in months

### Tech stack

- Python
- pandas, NumPy
- scikit-learn
- XGBoost
- Matplotlib, Seaborn
- Streamlit
- joblib

## Run locally

1. Install Python 3.10 or 3.11 (recommended).
2. Clone your repository and move into the project folder.
3. Create and activate a virtual environment.

   **Windows (PowerShell):**
   ```powershell
   py -3.11 -m venv .venv
   .venv\Scripts\Activate.ps1
   ```

   **macOS/Linux:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

4. Install dependencies:
   ```bash
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

5. Add the trained model and encoder artifacts listed in the repository structure.
6. Start the app:
   ```bash
   streamlit run app.py
   ```

Streamlit will print a local URL, usually `http://localhost:8501`.

## Model development

The notebook uses a stratified 80/20 train-test split and GridSearchCV with five-fold cross-validation. It compares Decision Tree, Random Forest, Extra Trees, and XGBoost classifiers using accuracy as the model-selection metric.

Recorded test-set accuracy in the current notebook:

| Model | Accuracy |
|---|---:|
| Decision Tree | 58.10% |
| Random Forest | 61.90% |
| Extra Trees | 64.76% |
| XGBoost | 67.62% |

The Streamlit app is loads the saved **XGBoost** model.

## Data and limitations

The notebook reads `german_credit_data.csv`.

- Results depend on the dataset, preprocessing, split, and hyperparameters.
- Encoded categorical values must use the same fitted encoders used during training.
- The model is not calibrated or validated for deployment.
- Credit decisions are high-impact decisions; bias, explainability, privacy, and applicable laws would need careful review before any real-world use.
